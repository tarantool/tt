# Дистрибутивы и модули {#дистрибутивы-и-модули}

tt состоит из ядра и набора модулей. Ядро разбирает командную строку,
находит проекты и scope и предоставляет сервисы, на которых строятся модули;
сами команды приходят из модулей. Модули бывают двух видов.

## Вкомпилированные модули {#вкомпилированные-модули}

Модуль tt - это модуль Go, скомпилированный в tt. Его пакет экспортирует
конструктор `func New(sdk.Services) []sdk.Mount`, возвращающий команды,
которые модуль добавляет, либо `func New(sdk.Services) sdk.Module`,
возвращающий также backend'ы сборки и проверки файлов пакета, добавляемые
модулем. Сам по себе tt - это ядро с его **стандартными модулями**:
`builtin`, его собственными командами, и модулями его репозитория,
перечисленными в пакете ядра `standard`: `aeon`, `build`, `emmylua`
и `wasm`. В модуле `build` находятся backend'ы сборки tt: у самого ядра
собственных backend'ов нет. В `wasm` находятся `tt wasm` и проверка файлов
`.wasm` пакета.

**Дистрибутив** tt - это ядро и набор модулей, собранных в один бинарный
файл и описанных в `tt.manifest.toml`. По умолчанию он берёт стандартные
модули своего ядра на коммите этого ядра и добавляет собственные модули;
он может исключить часть стандартных модулей или поставить на место одного
из них собственный модуль. Дистрибутив может представляться под другим
именем и в другой редакции, выбирать провайдер контроля целостности,
который [подписывает и проверяет пакеты](../how-to/sign-packages.md), и
исключать собственные команды tt или внешние модули.
`tt version --modules` выводит список модулей бинарного файла.

`tt binary build tt` собирает дистрибутив. См.
[Сборка дистрибутива tt](../how-to/build-distribution.md); API модулей
описан в [SDK](https://github.com/tarantool/tt/blob/v3/sdk/README.md).

## Внешние модули {#внешние-модули}

Внешний модуль - это исполняемый файл в каталоге модулей, который tt
запускает как собственную команду. Он может добавить команду или заменить
одну из команд tt. См. [Внешние модули](../how-to/external-modules.md).

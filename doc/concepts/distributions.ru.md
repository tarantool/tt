# Дистрибутивы и модули

tt состоит из ядра и набора модулей. Ядро разбирает командную строку,
находит проекты и scope и предоставляет сервисы, на которых строятся модули;
сами команды приходят из модулей. Модули бывают двух видов.

## Вкомпилированные модули {#compiled-in-modules}

Модуль tt - это модуль Go, скомпилированный в состав tt. Его пакет
экспортирует конструктор `func New(sdk.Services) []sdk.Mount`, возвращающий
команды, которые модуль добавляет. Сам по себе tt - это ядро с модулем
`builtin`, собственными командами и `aeon`.

**Дистрибутив** tt - это ядро и набор модулей, собранных в один бинарный
файл и описанных в `tt.manifest.toml`. Дистрибутив может представляться под
другим именем и в другой редакции, выбирать провайдер контроля целостности,
который [подписывает и проверяет пакеты](../how-to/sign-packages.md), и
исключать собственные команды tt или внешние модули.
`tt version --modules` выводит список модулей бинарного файла.

`tt binary build tt` собирает дистрибутив. См.
[Сборка дистрибутива tt](../how-to/build-distribution.md); API модулей
описан в [SDK](https://github.com/tarantool/tt/blob/v3/sdk/README.md).

## Внешние модули {#external-modules}

Внешний модуль - это исполняемый файл в каталоге модулей, который tt
запускает как собственную команду. Он может добавить команду или заменить
одну из команд tt. См. [Внешние модули](../how-to/external-modules.md).
